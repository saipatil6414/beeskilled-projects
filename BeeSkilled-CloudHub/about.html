PROJECT OVERVIEW

What is BeeSkilled CloudHub?

BeeSkilled CloudHub is a cloud-based serverless application designed to demonstrate practical implementation of AWS cloud services.

The project integrates frontend hosting, API management, serverless computing and NoSQL database services into a single cloud architecture.

It demonstrates how modern applications can be deployed without maintaining traditional backend servers.

Project Objectives

  • Deploy a web application on AWS
  • Implement serverless backend processing
  • Integrate REST APIs
  • Store application data in DynamoDB
  • Understand cloud architecture
  • Implement deployment automation
