# BeeSkilled CloudHub

## AWS Week 4 Capstone Project

BeeSkilled CloudHub is a serverless cloud application
developed as part of the BeeSkilled AWS Cloud Internship.

## Technologies

- HTML5
- CSS3
- JavaScript
- Amazon S3
- Amazon API Gateway
- AWS Lambda
- Amazon DynamoDB
- AWS CloudFormation
- AWS CodePipeline

## Architecture

User
↓
Amazon S3
↓
API Gateway
↓
AWS Lambda
↓
DynamoDB

## Features

- Responsive cloud dashboard
- AWS services showcase
- Cloud architecture visualization
- Project portfolio
- Serverless contact form
- DynamoDB data storage
- Cloud deployment

## AWS Services

### Amazon S3
Hosts the static website.

### API Gateway
Provides the REST API endpoint.

### AWS Lambda
Processes contact requests.

### DynamoDB
Stores contact information.

### CloudFormation
Supports infrastructure automation.

### CodePipeline
Supports CI/CD deployment.
